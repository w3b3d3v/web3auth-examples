# Story 1.2: Login UX and Network Configuration

## Status
Draft

## Story

**As a** user of the Web3Auth React Quick Start,
**I want** a reliable login experience with proper loading states and Passet Hub as the default network,
**so that** I have a smooth authentication flow and consistent network experience across the entire application.

## Acceptance Criteria

1. Login button only appears when Web3Auth provider is ready and initialized
2. Show appropriate loading states during provider initialization
3. Display warning message (NOT alert) when login fails to fetch user address, with reload suggestion
4. Set Passet Hub as the default network for the entire application
5. Ensure consistent network configuration throughout all app components
6. Maintain mobile-friendly user experience for all login states
7. After implementation, prompt user with suggested commit message before executing

## Dev Notes

### Current Implementation Context
Web3Auth integration is handled through hooks in `src/App.tsx` using `useWeb3AuthConnect`, `useWeb3AuthDisconnect`, and `useWeb3AuthUser`. Network configuration is defined in `src/wagmi-config.ts` and Web3Auth context in `src/web3authContext.tsx`.

### Technical Requirements
- **Main Files**:
  - `src/App.tsx` (login UI and state management)
  - `src/wagmi-config.ts` (network configuration)
  - `src/web3authContext.tsx` (Web3Auth provider setup)
  - `src/main.tsx` (provider initialization)
- **Provider Readiness States**:
  - `initializing`: Web3Auth provider is loading
  - `ready`: Provider ready for login
  - `error`: Provider failed to initialize
- **Default Network Configuration**: Passet Hub (ID: 420420422)
  - Chain name: "Passet Hub"
  - Native currency: PAS (10 decimals)
  - RPC: "https://testnet-passet-hub-eth-rpc.polkadot.io"
  - Explorer: "https://blockscout-passet-hub.parity-testnet.parity.io"
- **Warning Message Format** (not alert):
  ```tsx
  <div className="warning-message">
    ⚠️ Login successful but couldn't fetch your address. Try reloading the page.
  </div>
  ```
