# Story 1.1: Homepage Content and Educational Messaging

## Status

Done

## Story

**As a** user visiting the Web3Auth React Quick Start application,
**I want** to see clear educational messaging and intuitive interface that works on smartphones,
**so that** I understand how to interact with Asset Hub without a wallet extension and can easily access all functionality on any device.

## Acceptance Criteria

1. **Not Logged State**: Display educational message encouraging social login connection to "see what's possible"
2. **Logged State**: Add showcase messages highlighting key functionalities
3. **Logged State**: Add faucet button to get test funds
4. **Transaction Improvements**: Comment out ETH send transactions (keep code), add explorer links with transaction hash preview
5. **Mobile Responsiveness**: Ensure basic smartphone compatibility with readable text, appropriate button sizes, and proper layout
6. **Educational Focus**: Emphasize "no wallet extension needed" messaging throughout
7. **Transaction Explorer**: Mount explorer links using current connected chain's explorer
8. **After implementation**: Prompt user with suggested commit message before executing

## Dev Notes

### Current Implementation Context

The main interface is in `src/App.tsx` with `loggedInView` and `unloggedInView` components. The application uses CSS classes defined in `src/App.css` for styling.

### Technical Requirements

- **Main Files**: `src/App.tsx`, `src/App.css`
- **Mobile Breakpoints**: Use CSS media queries for responsive design
  - Mobile: `@media (max-width: 768px)`
  - Small mobile: `@media (max-width: 480px)`
- **Button Standards**: Minimum 44px height for touch targets
- **Typography**: Ensure text size ≥ 16px on mobile to prevent zoom
- **Educational Messaging Examples**:
  - Not logged: "👋 Connect with your social accounts to explore Web3 without wallet extensions!"
  - Logged: "🎯 Interact directly with Polkadot Asset Hub - no MetaMask required!"
- **Explorer Integration**: Use chain configuration from `wagmi-config.ts` blockExplorers
