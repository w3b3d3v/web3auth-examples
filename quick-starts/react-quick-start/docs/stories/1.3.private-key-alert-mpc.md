# Story 1.3: Private Key Export Alert Enhancement

## Status
Draft

## Story

**As a** user of the Web3Auth React Quick Start,
**I want** to see my private key in a native browser alert with educational information about MultiPartyComputation and MetaMask alternatives,
**so that** I understand the security advantages of Web3Auth's MPC technology over traditional wallet extensions like MetaMask.

## Acceptance Criteria

1. When user clicks the "Export Private Key" button, display the private key in a native browser alert (not custom UI)
2. Include educational message about MultiPartyComputation with MetaMask comparison
3. Provide link to Web3Auth MPC documentation: https://web3auth.io/docs/features/mpc1
4. Emphasize the advantage of not needing MetaMask or wallet extensions
5. Maintain all existing private key functionality and security
6. Alert should be mobile-friendly and readable on smartphones
7. After implementation, prompt user with suggested commit message before executing

## Dev Notes

### Current Implementation Context
The existing private key export functionality is located in `src/components/exportPrivateKey.tsx`. This component currently displays the private key in the UI after export using Web3Auth provider integration.

### Technical Requirements
- **File Location**: Modify `src/components/exportPrivateKey.tsx`
- **Alert Implementation**: Use native `window.alert()` for maximum browser compatibility
- **Educational Message Format** (with MetaMask comparison):
  ```
  🔐 Your Private Key: [PRIVATE_KEY]

  💡 Web3Auth Advantage: Unlike MetaMask which stores your key locally, Web3Auth uses MultiPartyComputation (MPC) technology. Your key is never fully assembled in one place - providing superior security without browser extensions!

  No MetaMask needed ✨

  Learn more about MPC: https://web3auth.io/docs/features/mpc1
  ```
- **Mobile Considerations**: Native alerts automatically handle mobile responsiveness
- **Security**: Ensure private key is still properly retrieved from Web3Auth provider
- **Chain Compatibility**: Must work with all configured chains (Passet Hub, Kusama Asset Hub, Westend, Ethereum Mainnet)

### Web3Auth Integration Patterns
[Source: architecture/web3-integration-patterns.md]
- Continue using existing `useWeb3AuthUser()` hook pattern
- Maintain Web3Auth provider access for private key retrieval
- Follow established error handling patterns for Web3Auth operations
- Preserve existing Web3Auth context integration

### Component Standards
[Source: architecture/component-standards.md]

### MetaMask Comparison Context
The educational message should emphasize:
- **MetaMask**: Stores private keys locally in browser, requires browser extension installation
- **Web3Auth MPC**: Distributes key shares across multiple parties, no single point of failure
- **User Benefit**: Same functionality without browser extension dependency
- **Security Advantage**: MPC provides better security model than local storage

### Testing Standards
[Source: architecture/testing-requirements.md]

- **Testing Framework**: Use Vitest with @testing-library/react
- **Test Coverage**: Unit tests for component behavior and alert content
- **Mock Requirements**: Mock Web3Auth provider and private key retrieval
- **Test Cases**:
  - Successful private key export displays native alert
  - Alert contains educational message with MetaMask comparison
  - MPC documentation link is included in alert message
  - Component handles Web3Auth errors gracefully
  - Alert text formatting is appropriate for mobile
  - Functionality works across all configured networks

### Security Considerations
- Private key must remain secure during alert display
- No logging or storage of private key values
- Maintain existing Web3Auth security practices
- Ensure alert doesn't expose key to other browser contexts
